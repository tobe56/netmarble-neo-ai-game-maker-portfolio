## AI 협업 방식

방향, 보존할 규칙, 최종 채택은 제가 정합니다. 세부 기획과 코드 구현은 AI에 맡기고, 결과는 실제 실행 화면과 자동 검사로 확인합니다.

- Claude Code 메인 세션 1개 + Sonnet 하위 에이전트 3~4개(각자 git worktree)
- 큰 오프라인 코드는 Codex 별도 브랜치로 맡기고, 메인이 시험을 다시 돌린 뒤 병합합니다.
- 보고는 `게임에서 됨 / 안 됨 / 아직 안 봄` 세 칸으로 받습니다.

원작 실행 파일·아트·음원과 비공개 저장소는 이 저장소에 포함하지 않습니다.
